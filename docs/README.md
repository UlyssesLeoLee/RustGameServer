# 文档体系

本目录管理RustGameServer项目的正式交付文档。文档编号规则为`RGS-<类别>-<序号>`。

文档体系遵循日本IPA（独立行政法人情报处理推进机构）的《要件定義書》标准框架（共通フレーム／非機能要求グレード），正文以中文撰写；框架层级的专有名词在首次出现处保留日文原名并附中文译名，因其为对日本标准的引用。

## 3. 文档管理规则

1. 全部文档在本仓库的`docs/`目录下由Git管理。
2. 版本号为`主版本.次版本`，仅**审批完毕**的版本持有主版本号。评审中的版本记为`0.x`。
3. 需求的变更必须记入**修订历史**，并明确标注受影响的需求ID。
4. 未决事项以`【TBD-nnn】`记载于正文，并同时登记至附件D问题管理表。正文中不得遗留未登记的TBD。
5. 本编与附件记述矛盾时，**以本编为准**。
6. 需求定义书（RGS-REQ-001）与基本设计书（RGS-BAS-001）记述矛盾时，**以需求定义书为准**——基本设计书是需求定义书第10章的展开，不得在设计阶段变更架构决定；如确需变更，须先修订需求定义书对应的ARC-nnn并走ADR流程。
