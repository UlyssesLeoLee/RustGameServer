## 与原 WBS 53.10 范围差异说明

WBS v0.3 §2A.5 WF-1-53.10 描述："5 独立 PG 18.6 DB 容器（player_db / economy_db / match_db / social_db / admin_db + cluster_ops_db）"。

**实施选择**：
- WBS 原计划 5 个独立 DB 容器
- 实际部署 = **单 PG 容器 + 6 独立 schema**（dev 接受，多容器化在 57.x prod profile）
- 理由：dev 阶段降低资源消耗（k3s 单节点 5 DB 容器 vs 1 容器 6 schema 资源差 5 倍）
- ARC-008 "5 独立 DB 原则" 在 schema 级别保持（每个域独立 schema + user）
