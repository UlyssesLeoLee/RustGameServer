# 1. 背景与范围

## 1.1 背景

`crates/gm-extra-service/` 是 RGS 7 域扩展下独立拆分的 GM 扩展微服务。其设计**承接** gm-backend 既有的 GM 管控核心能力，但承担**GM 扩展**功能：批量操作 / 高级查询 / 运营报表 / 审计追溯等。

本域覆盖 1 个 gRPC service（GmExtraService）、10 个 RPC（含 1 HealthCheck）。其中 6 RPC 为真实业务逻辑（批量封号 / 高级查询 / 运营报表），4 RPC 为 Unimplemented stub。

## 1.2 范围边界

**In-Scope**：

- 批量 GM 操作（批量封号 / 批量补偿 / 批量解封）
- 高级查询（玩家全维度画像 / 服务器状态全景）
- 运营报表（每日 / 每周 / 每月）
- 审计追溯（GM 操作日志的二次查询）

**Out-of-Scope**：

- 单玩家 GM 操作（属 gm-backend 既有）
- GM 后台 UI（属前端范畴）
- RBAC 权限矩阵（属 RGS-REQ-007 既有）

## 1.3 与既有基础设施的关系

| 既有机制 | 本域使用方式 |
|---|---|
| gm-backend 既有 | 单玩家 GM 操作**严格**复用既有 |
| ARC-008 5 独立 DB → 7 域扩展 | 落位独立 `gm_extra_db`（仅运营/审计） |
| RGS-REQ-007 RBAC | 批量操作同样经 RBAC 校验（per RGS-BAS-003） |
| ARC-026 OLU 预算 | 批量操作**必须**在 OLU 预算台账内（per RGS-REQ-013） |

# 3. 业务需求 (BR)

## BR-GMX-001 批量 GM 操作

- 批量封号（按条件筛选 + 批量封禁）
- 批量补偿（按账号 / 全服 / 活动）
- 批量解封

**验收**：批量操作可发起 + 进度查询 + 结果回调。

## BR-GMX-002 高级查询

- 玩家全维度画像（账号 + 角色 + 经济 + 战斗 + 社交）
- 服务器状态全景（在线人数 / 各域负载 / 经济总量）

**验收**：两类查询均能 CRUD + 权限过滤。

## BR-GMX-003 运营报表

- 日报 / 周报 / 月报
- 业务指标：DAU / 留存 / ARPPU / 战斗次数 / PVP 次数

**验收**：报表可生成 + 导出 CSV / Excel。

## BR-GMX-004 审计追溯

- GM 操作日志的二次查询（按时间 / 操作人 / 目标类型）
- 审计日志导出（合规需求）

**验收**：审计可查询 + 导出。

# 4. 功能需求 (FR)

## 4.1 批量操作

|---|---|
| FR-GMX-001 | `BatchBan` **必须**支持条件筛选 + 批量封禁（每批次 ≤ N） |

| FR-GMX-003 | 批量操作**必须**支持进度查询（per BatchOpId） |
| FR-GMX-004 | 批量操作**必须**支持结果回调（成功 / 失败 / 部分失败） |

| ID | 需求 |

| FR-GMX-011 | `GetServerStatus` **必须**支持在线人数 + 各域负载 |
| FR-GMX-012 | 查询**必须**经 RBAC 校验（per RGS-REQ-007 §3） |

## 4.3 运营报表

| FR-GMX-022 | 报表生成**必须**经 ARC-026 OLU 预算台账校验 |

# 6. 架构设计方针 ARC-052

## 6.1 ARC-052：GM 扩展 + 复用 gm-backend 既有管控原则

| 项目 | 内容 |
|---|---|
| **决定** | GM 扩展域仅承担"批量 / 高级查询 / 运营报表 / 审计追溯"4 类扩展功能；单玩家 GM 操作**严格**复用 gm-backend 既有 |
| **理由** | 避免与既有 gm-backend 重复建设，聚焦"批量 + 高阶分析"GM 工具扩展能力 |
| **承载机制** | 批量规则 / 报表规则 / 审计过滤规则作为 ARC-021 既有插件通道承载 |
| **否决方案** | "在 gm-extra 内自建单玩家 GM 操作 / 自建 RBAC"——直接违反既有职责，已否决 |
| **适用范围** | 本域所有 GM 扩展功能（批量 / 查询 / 报表 / 审计） |
