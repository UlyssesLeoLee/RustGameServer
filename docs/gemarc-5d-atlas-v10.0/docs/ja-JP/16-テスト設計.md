## 16.3. Case との対応

| Case | 種別 | 起点 | 期待結果 |
|---|---|---|---|
| `CASE-001` | Normal | economy 交易 saga 正常完成 | SUCCESS — saga 提交, 无补偿 |
| `CASE-002` | Compensation | saga 中途失败 → 真实补偿链 | COMPENSATED — 资源回滚, 与 chaos_trade_saga_compensation.rs 的测试意图 |
| `CASE-003` | Retry | 重试退避 (真实 RetryConfig) | FAILURE — 达到 max_retries=3 后放弃 (退避上限 30000ms) |
| `CASE-004` | Boundary | 退避达到 max_interval 上限 | FAILURE — 退避封顶, 不无限增长 |
| `CASE-005` | DuplicateDelivery | Outbox 重复投递 (幂等约束) | SUCCESS — 无重复副作用 (幂等) |
| `CASE-006` | FailurePropagation | gm-backend → admin-service 熔断 (真实 CircuitBreaker) | FAILURE — 熔断生效, 防止 cascade failure |
| `CASE-007` | Recovery | 熔断后恢复 (HalfOpen probe 成功) | SUCCESS — 熔断器复位 |
| `CASE-008` | Timeout | economy → card-service 超时 (仅设计意图, 无真实调用点) | FAILURE — 重试耗尽 (设计意图, 非实测) |
| `CASE-009` | Concurrent | 并发 saga 下的库存预留冲突 | BLOCKED — 资源竞争被检出 |
