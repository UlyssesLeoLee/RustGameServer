## 5.1. 構成

```
System: RustGameServer
└── Building: k3s / rust-game-server
    ├── Floor: Core          (7 crates)
    ├── Floor: Interaction   (3 crates)
    ├── Floor: Data          (8 crates)
    ├── Floor: Security      (2 crates)
    ├── Floor: Infrastructure(3 crates)
    ├── Floor: External      (5 crates)
    ├── Floor: Operations    (1 crates)
    └── Floor: Unknown       (2 crates)
```

> **投影の性質**: 上記の Floor / Room は**論理投影**であり、物理的な机房トポロジではない。
> 実際の k8s Deployment 情報は各 Service ノードの `deployment` 属性に保持される。
