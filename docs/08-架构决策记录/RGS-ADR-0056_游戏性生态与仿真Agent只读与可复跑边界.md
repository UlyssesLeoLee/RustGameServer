## 1. 决策背景

`RGS-REQ-035 v0.2` 已明确"游戏性 Agent 在离线或近线环境生成候选结论，生产变更仍由确定性发布链与人类决策者控制"——但本方针尚未在 ADR 层面固化。需建立治理框架以处置：

1. **生产与仿真边界**：蒙特卡洛宏观推演（FR-AGS-001）、NPC 记忆-反思-规划（FR-AGS-002/003）、数值极端流派碰撞仿真（FR-AGS-004）必须严守"只读 + 离线/近线 + 可复跑"三原则（per `RGS-REQ-035 §3 NFR-AGS-001/002/003`）。
2. **OLU 预算约束**：仿真规模、可接受误差、资源配额和结果采纳门槛尚未量化（per `RGS-REQ-035 §7 TBD-AGS-001`），PH-5 前须具名人类审批。
3. **平台层依赖**：与 `RGS-ADR-0054`（智能体平台统一运行时，待审批）同层；ARC-056 不强制独立平台，但**若 ADR-0054 后续被驳回，本 ADR 候选 C 可能与"复用 LangGraph 既定路径"重叠，须在 PH-5 前收敛**。

---

## 2. 候选决策内容（待审批）

1. **候选 A：维持 `RGS-REQ-035 §3 NFR-AGS-001〜003` 三层只读 + 可复跑 + 资源隔离基线**（不修改需求文本），在 ADR 层面固化"候选"为治理框架。
2. **候选 B：将仿真与 NPC Agent 矩阵统一纳入 ARC-027 智能层既有 LangGraph 路径**，复用 `RGS-REQ-014` 既定离线/近线基础设施，不新增平台层（候选与 `RGS-ADR-0054` 互斥，须 Ulysses 拍板二选一）。
3. **候选 C：保留 ARC-056 为治理框架，但 BR-AGS-001/002/003 业务范围、TBD-AGS-001 仿真规模/误差/配额/采纳门槛在附件D 长期悬置**，由 PH-5 前架构师 + 游戏设计 Lead + SRE Lead 具名审批后再决定（与 `RGS-ADR-0058` 候选 C 同模式）。

## 4. 与既有文档/约束的接口

- **ARC-056 ↔ ARC-027 ↔ ARC-053 ↔ ARC-054 ↔ ARC-055 关系**：ARC-056 是"只读边界 + 可复跑证据"治理框架；ARC-027 是智能层运行时；ARC-053/0054/0058 是 SRE/客服/平台/运营 Agent 边界。**候选 B vs 候选 A**会触发"是否独立平台层"的取舍，须 Ulysses 拍板。
- **附件D §3 登记行同步**：本 ADR 通过具名人类审批后，附件D §3 ADR-0056 行的"待具名人类审批・未制定正文"标签**仍保留**——**只有 Ulysses 本人签字后才升级为 Accepted**，期间附件D §3 行的"状态"文字不变（per `RGS-DOCS-HEALTH-2026-08-25-feedback-to-agents.md` §4 处置 3）。
- **NFR-AGS-001 既定"只读边界"**：本 ADR 不修改该 NFR；候选 A 直接承接，候选 B/C 也以其为下限。
