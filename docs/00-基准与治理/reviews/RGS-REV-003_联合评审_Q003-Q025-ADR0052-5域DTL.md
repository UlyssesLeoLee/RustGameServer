### §3.1 5 域 Lead 分配（领域智能 + DEC-005 不兼任原则）

> **v0.5 DEC-005 翻转**：原"架构师兼任 player / SRE 兼任 admin"兼任方案取消；5 域 Lead 必须**独立**配置。理由：兼任把责任矩阵和 RACI 模糊化；Q-003 Saga 跨域核心问题需要 economy 域 Lead 独立决策权；COC 控制面属 admin 域独立控制面，SRE 兼任会与 admin 域 Lead 责任重叠。

| 域 | 智能选择 | 理由 |
|---|---|---|
| **Player 域** | **Player 域 Lead**（独立，per DEC-005）| player 是 entry point + 简单 KV 域；架构师**不**兼任；需专人负责 PII / 实名 / 登录态 |
| **Economy 域** | **Economy 域 Lead**（独立，Q-003 二次确认）| Q-003 Saga 跨域核心，最复杂；需独立决策权 + 二次确认 Q-003 |
| **Match 域** | **Match 域 Lead**（独立，Gameplay Engineer）| 性能敏感（NFR-PT 100ms 决策）；需游戏逻辑专家独立签字 |
| **Social 域** | **Social 域 Lead**（独立，Messaging Engineer）| 异步消息 + 跨域引用；需消息/通知专家独立签字 |
| **Admin 域** | **Admin 域 Lead**（独立，per DEC-005）| COC 控制面属 admin 域独立控制面；SRE **不**兼任（兼任会与 admin 域 Lead 责任重叠）|

## §4 评审流程

### §4.1 阶段 1：预读（启动后 3 天内）

每个责任人阅读本评审 + 附件 + 相关 DTL/SPEC/ADR。预读发现的问题记录在 §6 异议登记表中。

### §4.2 阶段 2：会议评审（启动后 7 天内）

- 主持：架构师
- 出席：所有 §3 责任人
- 时长：≤ 2 小时
- 议程：见 §5

### §4.3 阶段 3：闭环（评审后 5 天内）

- 每个异议必须以文档/ADR 修订闭环
- 修订后再走 §4.1 + §4.2 一轮（最多 2 轮）
- 第 2 轮仍未闭环的，按 handoff §1 升为 NO-GO，53 不可启动
