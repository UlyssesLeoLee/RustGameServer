## ⚠️ 异常处理

| 情况 | 处理 |
|---|---|
| 必到人员无法出席 | 提前 48h 通知, 由其指定代理人 (需 §3 责任矩阵确认) |
| 视频会议中断 | 切换到备选平台, 会议纪要标注中断时段 |
| 议程超时 | 16:00 硬结束, 未讨论项进入阶段 3 异步闭环 |
| 关键异议现场未闭环 | 标记 🔴, 升级技术 VP, 53 仍为 NO-GO |
| 全体不同意签字 | 按 handoff §1 进入推迟评估, RGS-PLAN-001 修订 |
