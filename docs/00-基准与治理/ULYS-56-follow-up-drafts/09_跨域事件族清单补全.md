## 3. 新域 Onboarding 流程 (候选)

**触发**: RGS 新增业务域（如 PH-7 资产下载域 / PH-7 GM 后台 / 待定的其他域）须引入 outbox 事件传播。

### 3.1 Onboarding 步骤

| 步骤 | 内容 | 责任方 | 产物 |
|---|---|---|---|
| 1 | 新域 RGS-REQ-NNN 需求定义书 (per ARC-001 场景模型) | 架构师 + 域 owner | 需求定义书 |
| 2 | 新域 outbox 表 migration 创建（按 `0003_outbox.sql` 模板） | 域 owner + DBA | `crates/{service}/migrations/0003_outbox.sql` |
| 3 | 新域 main.rs 集成 outbox relay (per `crates/admin-service/src/main.rs` 模式) | 域 owner | `crates/{service}/src/main.rs` |
| 4 | 新域事件族清单登记 (per §2 模板) | 域 owner + 架构师 | RGS-SPEC-CROSS-003 v0.3+ §X 主题命名空间扩展 |
| 5 | 新域集成测试 (per `crates/economy-service/tests/integration_outbox.rs` 模式) | 域 owner + QA | `crates/{service}/tests/integration_outbox.rs` |
| 6 | 新域监控指标接入 (per P2-#2 监控指标草案 §1) | SRE Lead | `rgs_outbox_*` 指标按 `{service}` label 自动出现 |
| 7 | DLQ 接入 (per P2-#3 DLQ 草案 §2.2) | 架构师 + DBA | `crates/{service}/migrations/0006_outbox_dlq.sql` |
| 8 | 文档基线交接 (per RGS-HANDOFF-001) | 架构师 | 域 onboarding 完成 |

### 3.2 Onboarding 准入检查

**强制项**:
- [ ] 域需求定义书已审批
- [ ] outbox 表 migration 已通过 `check-outbox-schema-consistency.sh` CI 校验（per P2-#4 Schema Evolution §2.2）
- [ ] 事件族清单已登记至 RGS-SPEC-CROSS-003
- [ ] 集成测试覆盖事务内强制 outbox 写入约束（per ADR-0061 §2 决定 2）
- [ ] DLQ 表已创建并通过 schema 契约测试
- [ ] 监控指标已暴露 `rgs_outbox_*` 三项 (pending / inflight / failed)

**推荐项**:
- [ ] Poison event 处置 SOP 已就位
- [ ] 域 owner 已加入 SRE on-call 名单
- [ ] 性能压测覆盖 outbox throughput（NFR-PE-011 兼容性）
