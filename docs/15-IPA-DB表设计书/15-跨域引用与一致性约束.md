## 1. 跨域弱引用原则（per RGS-SPEC-CROSS-005 §2）

**核心原则**：跨 DB 禁用外键。

| 規則 | 内容 | 理由 |
|---|---|---|
| **同库内** | 物化 FK（`FOREIGN KEY ... REFERENCES`）| 强保证 + DB 层 CASCADE 性能 |
| **跨库 / 跨域** | 不物化 FK，应用层校验存在性 | 跨服务边界会引入强耦合 + 服务间可用性依赖 |

**应用层责任**：
- 写入前 existence check（`SELECT 1 FROM <remote_table> WHERE id = ?`）
- 删除时 tombstone 处理（被引用方删除时通知引用方）
- 缓存 + TTL 减少远程调用频次

## 3. 同库内应物化的 FK（P1-05 / P1-12 / P1-16）

### 3.1 `transaction_ledger.saga_id` → `sagas.id`（同库，P1-05）

- 现状：`saga_id UUID` 弱引用，**同库未物化**
- 风险：saga 删除时 ledger 残留孤儿
- 建议 PH-2 评审：物化 `FOREIGN KEY (saga_id) REFERENCES sagas(id) ON DELETE RESTRICT`

### 3.2 `audit_log.actor_id` → `admin_users.id`（同库，P1-16）

- 现状：弱引用，**同库未物化**
- 风险：admin_users 删除（极少见）时 audit_log 残留孤儿
- 建议 PH-2 评审：物化 `FOREIGN KEY (actor_id) REFERENCES admin_users(id) ON DELETE RESTRICT`

### 3.3 `game_sessions.match_id` ↔ `matches.id`（同库，P1-05）

- 现状：跨 migration 的两个表（0001 matches + 0040 game_sessions）**同库未物化**
- 风险：卡牌游戏用 game_sessions 取代 matches，但旧 matches 表仍保留
- 建议 PH-2 评审：物化 OR 决定废弃 matches 旧表

### 3.4 `card_instances.card_id` → `cards.card_id`（同库，P1-12）

- 现状：弱引用，**同库未物化**
- 风险：card catalog 删除时 card_instances 残留孤儿
- 建议 PH-2 评审：物化（但要考虑卡牌下架场景是否需要保留 instance）

### 3.5 `matchmaking_tickets.match_id` → `game_sessions.match_id`（同库，P1-05）

- 现状：弱引用，**同库未物化**
- 风险：session 删除时 ticket 残留
- 建议 PH-2 评审：物化 `FOREIGN KEY (match_id) REFERENCES game_sessions(match_id) ON DELETE SET NULL`（matched ticket 不应随 session 删除而级联）

### 3.6 其他同库内可物化

- `cards.series_id` → `card_series.series_id`（同库，P1-12）
- `outbox.saga_id` → `sagas.id`（**跨 DB**，不强求物化）
- `merge_conflict_rule_set_v2.locked_by` → `admin_users.id`（同库，可物化）
- `realm_lifecycle_run.operator_id` → `admin_users.id`（同库，可物化）
- `audit_log.actor_id` → `admin_users.id`（同库，可物化）

## 4. 一致性约束缺失清单（应用层强保证 vs DB 层弱保证）

### 4.1 状态机一致性（缺 DB CHECK）

| 表 | 状态机 | 缺哪些 CHECK |
|---|---|---|
| `matches` | waiting → in_progress → finished / cancelled | `((status = 'finished') = (winner_team IS NOT NULL))` `((status IN ('finished', 'cancelled')) = (ended_at IS NOT NULL))` |
| `game_sessions` | creating → waiting → starting → running → turn_n → paused → ending → ended / canceled | `((status = 8) = (ended_at IS NOT NULL))` `((status = 8) = (winner_id IS NOT NULL))` |
| `sagas` | pending → running → compensating → completed / failed / aborted | `((status IN ('completed', 'failed', 'aborted')) = (completed_at IS NOT NULL))` |
| `audit_log` | (append-only) | (已用触发器) ✅ |
| `moves` | (one-shot) | `((accepted = TRUE) = (reject_reason IS NULL))` |
| `outbox` | pending → in_flight → sent / failed | (已有 CHECK) ✅ |

### 4.2 跨列一致性

| 表 | 缺哪些跨列 CHECK |
|---|---|
| `decks` | `((is_public = FALSE) AND (share_code IS NULL)) OR ((is_public = TRUE) AND (share_code IS NOT NULL))` |
| `i18n_languages` | (partial unique 已保证至多 1 default) 缺 `(is_default = TRUE) = (enabled = TRUE)` |
| `feature_flags` | `(scope, scope_value)` 一致性（global="" / domain=域列表 / node=hostname 列表）|
| `matchmaking_tickets` | `rank_score_min <= rank_score_max` |
| `private_trades` | `proposer_id <> counterparty_id` |
| `card_instances` | `NOT (tradable = FALSE AND locked = FALSE)` |
| `leaderboard_entries` | `(leaderboard_type = 'ranked') = (season_id <> '')` |
| `session_subscriptions` | `closed_at IS NULL OR closed_at > created_at` |
| `replays` | `expires_at > created_at` |
| `merge_conflict_rule_set_v2` | 锁定后禁 UPDATE/DELETE（需触发器，per ARC-023 极窄允许）|

### 4.3 数值范围

- 已大部分覆盖（`level BETWEEN 1 AND 999` / `crit_rate BETWEEN 0.0 AND 1.0` / `slot BETWEEN 0 AND 199` / `archive_threshold_days BETWEEN 30 AND 90` 等）
- 缺 `rank >= 0` / `wins >= 0` / `losses >= 0` / `payload_size >= 0` / `duration_secs >= 0` / `object_size >= 0`（leaderboard / replay / resume_tokens 等）

## 6. GDPR 合规（per NFR-SE-010 双层审计）

> per RGS-DTL-018 §3.1 玩家删除走**双层审计通路**：
> 1. `admin_db.audit_log` 记录删除事件（hash 链防篡改）
> 2. 应用层 CASCADE 清理跨域引用

**应用层 CASCADE 责任**（当 player 删除时）：

| 跨域引用 | 清理方式 |
|---|---|
| `accounts` (economy_db) | 应用层 DELETE WHERE player_id = ? |
| `match_participants` (match_db) | 应用层 DELETE WHERE player_id = ? |
| `game_sessions.players[]` (match_db) | 应用层 JSONB 移除该 player_id |
| `matchmaking_tickets` (match_db) | 应用层 DELETE WHERE player_id = ? |
| `moves` (match_db) | 应用层 DELETE WHERE player_id = ?（**风险：破坏回放完整性**——见 [17-P1-17](17-不合理设计识别与优化建议.md)）|
| `guilds.leader_id` (social_db) | 应用层转移会长 / 解散公会 |
| `guild_members` (social_db) | 应用层 DELETE WHERE player_id = ? |
| `card_instances.owner_id` (card_db) | 应用层转移所有权或删除（业务决策）|
| `decks.owner_id` (player_db) | 应用层 DELETE WHERE owner_id = ?（**已有 app-layer CASCADE 标注**）|
| `player_inventory.player_id` (player_db) | **DB 层 ON DELETE CASCADE** ✅ |
| `player_characters.player_id` (player_db) | **DB 层 ON DELETE CASCADE** ✅ |
| `player_sessions.player_id` (player_db) | **DB 层 ON DELETE CASCADE** ✅ |
| `replays.player_a/b` (replay_db) | 应用层 SET player_id = 'ANONYMIZED_<hash>'（保留回放历史）|
| `auctions.seller_id` / `highest_bidder` / `winner_id` (economy_db) | 应用层 NULL 化（避免破坏拍卖历史）|

> **`moves` 删除破坏回放完整性** —— 重要 P1 不合理设计，详见 [17-P1-17](17-不合理设计识别与优化建议.md)。
