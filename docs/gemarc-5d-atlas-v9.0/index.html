快速开始

5D Atlas 不是"另一种设计模板", 而是把"为什么 / 是什么 / 怎么用 / 长什么样 / 怎么上线"分成可分别校验的 5 维:

  1. D1 — 先对齐"为什么做、给谁做、怎样算成功", 不对齐前不进 D2。
  2. D2 — 把价值主张拆成可被找到/理解/信任的内容结构。
  3. D3 — 把 IA 串成可验证的关键旅程与状态机, 不要只画 happy path。
  4. D4 — 用 token + 组件库 + 栅格, 把旅程做成可看的页面。
  5. D5 — 把页面做成可部署/可监控/可回滚/可演化的工程产品。

每层都有 模板 (照填) + 出口判据 (不达不往下走) + 与其他层的接口 (防止脱节)。

如何使用: 项目启动时, 从 D1-concept-brief.template.md 开始。填完跑 D1-checklist.md, 全部勾选才进 D2。

治理与已知缺口

input 完全为空字符串 — 项目名/用户需求/目标仓库/local folders/需求文档/UI 参考 全部 "" 或 []。本 atlas 作为通用方法论交付, 不可作为任何真实项目的设计直接落库。使用前必须用真实输入替换或绑定到具体项目。

本 atlas 的承诺 - 方法论 / 模板 / 清单 / 集成校验 / 假设性示例 - 完全离线可用, 单 HTML 入口, 不依赖 npm 构建 - 与 visual-page / web-design 类需求解耦, 不绑定任何视觉品牌

本 atlas 不承诺 - 任何具体项目的设计交付 (input 为空) - 真实数据 / 真实用户验证 (示例均为假设) - 凭据 / 监管 / 版权合规 (必须由使用方自查)

已知缺口 (汇总, 详见 QA_FINAL.md) - 项目名 = auto 未指定 - 用户需求 = [] - 目标仓库 / 本地文件夹 / 参考仓库 = 空 - UI 参考 = 空 (仅空白 path: "" + url: "") - 合规 / 监管 / 不可逆决策 = 无任何外部证据 - 所有"反向假设 / 反对者签字"为占位, 待真实项目替换
