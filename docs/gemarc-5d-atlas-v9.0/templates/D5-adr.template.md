## 编写守门
- 每条 ADR 必须有日期 + 修订人 + 审批人
- 至少 2 个备选方案 (拒绝"就这一个")
- 撤销条件必须可观察 (不是"未来再看看")
- 弃用 / 取代必须引用被取代的 ADR
