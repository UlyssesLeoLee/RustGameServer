# D2 出口校验清单

> 自检用。先填 D2-ia-map.template.md。

## A. 内容模型

- [ ] 每个实体都有字段列表 + 状态机 + 关联
- [ ] 每个字段有"为什么必须有"答案
- [ ] 类型 / 默认值 / 校验齐全

## B. 分类法

- [ ] 每个维度标注互斥 / 非互斥
- [ ] 互斥维度在 UI 表现为单选
- [ ] 非互斥维度同时筛选项 ≤ 3

## C. 站点地图

- [ ] L0 ≤ 7 项
- [ ] L1 ≤ 9 项/分组
- [ ] 每个 L1 节点有示例

## D. 多入口

- [ ] 每个核心对象 ≥ 3 个独立入口
- [ ] 入口路径覆盖 3 类用户场景 (浏览 / 搜索 / 私域)

## E. 同义词表

- [ ] 规范词单一定义
- [ ] 同义词覆盖搜索长尾 (爬 query log)
- [ ] 无词义冲突

## F. 检索

- [ ] 索引范围明确
- [ ] 排序规则透明
- [ ] 0 结果兜底可点 (猜你想找 / 热门)

## G. IA 演化 lint

- [ ] 新节点空 90 天 → 阻止
- [ ] 重叠 ≥ 50% → 提示合并
- [ ] 流量 < 0.1% → 季度评审
- [ ] 删除前 301 重定向

## H. 已知缺口

- [ ] 列了未采样流量 / 同义词盲区 / 分类歧义

---

## 通过标准
A-H 全部 ☑。

## 反模式
- ❌ "导航很清晰,大家都在首页能找到" → 没有数据 = 没测过
- ❌ 分类用"杂项 / 其他" → 收容类信息藏在收容桶里
- ❌ L0 11 项 → Miller 7±2 已破
- ❌ 同义词表凭脑补 → 一定漏
