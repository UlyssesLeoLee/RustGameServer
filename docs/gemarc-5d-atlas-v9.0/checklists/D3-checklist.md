# D3 出口校验清单

## A. 关键旅程

- [ ] ≤ 7 条 (拒绝"还有这条重要")
- [ ] 每条 Persona 都来自 D1
- [ ] 每条对 D1 NSM 有显式贡献
- [ ] 频次 / 时长预算写过

## B. 旅程规格 (每条都跑)

- [ ] 入口 ≥ 3 个
- [ ] happy path + error path 都画了
- [ ] 每个 step 至少 1 条错误路径
- [ ] 撤销窗口明确
- [ ] 上下行 payload 写明
- [ ] 监控事件已埋点

## C. 状态机

- [ ] ≤ 7 个对象,每个都画图 + 转移矩阵
- [ ] 每个转移有守卫条件
- [ ] 每个转移有副作用 / 审计记录
- [ ] 无"无脑态变"

## D. 表单

- [ ] 必填 ≤ 7 项
- [ ] 即时校验 + 提交校验
- [ ] 错误显示在出错字段
- [ ] 不可逆操作有二次确认 / undo

## E. 错误兜底 (5 类)

- [ ] 网络: 重试 + 离线草稿
- [ ] 业务: 404 / 403 路径
- [ ] 权限: 不暴露原因
- [ ] 数据: 保留输入 + 字段错误
- [ ] 系统: 全局兜底页 + 反馈入口

## F. A11y

- [ ] Tab 顺序正常
- [ ] aria-live 触发动态变更
- [ ] 色盲模拟下可识别状态
- [ ] prefers-reduced-motion 已实装
- [ ] 触控 ≥ 44×44 px

## G. 监控

- [ ] 关键旅程进入 / 完成 / 放弃埋点
- [ ] 错误码分类埋点
- [ ] 时长 P50 / P95 指标

## H. 已知缺口

- [ ] A11y 真人验证状态
- [ ] 错误路径覆盖率
- [ ] 撤销窗口经验值

---

## 通过标准
A-H 全部 ☑。

## 反模式
- ❌ 只画 happy path → 用户掉坑没人接
- ❌ 状态机画了但无守卫条件 → 任意态变 = 数据脏
- ❌ 表单 12 项 → 完成率 < 30%
- ❌ 错误兜底只一句"加载失败" → 没指引 = 死胡同
