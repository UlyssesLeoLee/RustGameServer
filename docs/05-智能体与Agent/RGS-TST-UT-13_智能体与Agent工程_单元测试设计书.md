## 1. 测试用例清单

| 用例编号 | 对应需求/验收 | 测试目标 | 预期结果 |
|---|---|---|---|
| **UT-AGT-001** | FR-AGP-005、NFR-AGO-001、AC-AGO-001 | L0 闸门签名验签测试 | 正确 Ed25519 签名验签通过，伪造签名立即返回 `SignatureInvalid` 并审计。 |
| **UT-AGT-002** | FR-AGO-003、NFR-AGO-001、AC-AGO-003 | 单人补偿配额硬超限拦截 | 提交超出权威配额的候选金额时，闸门强阻断并记录安全告警。 |
| **UT-AGT-003** | FR-AGO-003、NFR-AGO-001/002、AC-AGO-001 | 订单号/nonce 重放攻击拦截 | 重复提交相同 `order_id` 或 nonce 时，闸门返回拒绝回执且不重复结算。 |
| **UT-AGT-004** | FR-AGP-004、NFR-AGO-002、AC-AGO-004 | Prompt Injection 注入防御 | 输入恶意提示词时，结构化输出仍须经过 Schema、证据与闸门校验，不能绕过权限边界。 |
| **UT-AGT-005** | FR-AGS-001/004、NFR-AGS-002、AC-AGS-001 | 仿真可复跑性 | 相同快照、版本、随机种子和参数可复跑，并产出可比较的输入/输出摘要。 |
| **UT-AGT-006** | FR-AGS-002/003、NFR-AGS-001、AC-AGS-002 | 游戏性 Agent 的 L0 写边界 | 尝试写入玩家资产、线上数值或结算状态时，调用被拒绝并写入审计记录。 |
