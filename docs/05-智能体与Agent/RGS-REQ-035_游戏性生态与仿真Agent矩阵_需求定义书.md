## 1. 业务需求（BR）

| 编号 | 业务需求名 | 业务目标 | 阶段 |
|---|---|---|---|
| **BR-AGS-001** | 宏观经济演化与通胀预测 | 离线/近线推演百万级玩家交易行为，预测游戏币与稀有道具通胀拐点 | PH-5 |
| **BR-AGS-002** | 沉浸式动态 NPC 交互 | NPC 具备记忆、个性性格与动态目标，根据玩家历史互动自适应生成对话与剧情分支 | PH-6 |
| **BR-AGS-003** | 战斗数值平衡压力仿真 | 自动化生成万种技能搭配与装备流派，跑出胜率分布与极端数值漏洞（Exploit） | PH-5 |

## 2. 功能需求（FR）

| 需求编号 | 需求名称 | 详细说明 | 优先级 |
|---|---|---|:---:|
| **FR-AGS-001** | 蒙特卡洛宏观经济推演引擎 | 模拟不同产出/消耗配比下的物价曲线，输出未来 30 天通胀预警指数 | ◎ |
| **FR-AGS-002** | NPC 记忆-反思-规划状态图 | NPC 自动将事件存入长期记忆，定期触发 Reflection 生成高阶认知并调整日程目标 | ◎ |
| **FR-AGS-003** | NPC 情感与好感度动态演变 | 根据玩家对话语义与行为好恶，动态计算情感矩阵并影响交易折扣与隐藏任务解锁 | ○ |
| **FR-AGS-004** | 数值极端流派碰撞仿真 | 强化学习智能体相互对战，探索极端属性叠加（如 100% 闪避、无限连击）并标红预警 | ◎ |

## 3. 非功能需求（NFR）

| 编号 | 区分 | 指标要求 |
|---|---|---|
| **NFR-AGS-001** | 确定性边界 | NPC、经济与数值 Agent 仅输出对话、建议或候选配置；不得直接修改玩家资产、战斗结算、线上数值或其他 L0/L1 状态。任何变更均须走既有确定性发布与具名审批流程。 |
| **NFR-AGS-002** | 可复现性 | 每次仿真或反思结果必须记录数据快照标识、模型/提示词或策略版本、随机种子、执行参数与输出摘要，以便复跑、审计和回归比较。 |
| **NFR-AGS-003** | 资源隔离 | 仿真与长时推理不得位于实时 tick 或账本写路径；超时、配额耗尽或模型故障只能降级相关 Agent 功能，不得影响在线会话一致性。 |

---

## 4. 架构方针（ARC-056，提案，待具名人类审批）

**“游戏性 Agent 在离线或近线环境生成候选结论，生产变更仍由确定性发布链与人类决策者控制。”**

本方针尚未构成已批准架构决定。上线任何会影响经济、战斗或玩家权益的自动化能力前，必须完成架构、安全、运营与项目负责人的具名评审，并登记 ADR、OLU 与风险处置结果。

---

## 5. 验收标准（AC）

| 验收编号 | 通过标准 | 关联需求 |
|---|---|---|
| **AC-AGS-001** | 同一数据快照、模型/策略版本、随机种子与参数可复跑，并能比对输入与输出摘要。 | FR-AGS-001/004、NFR-AGS-002 |
| **AC-AGS-002** | NPC 或仿真 Agent 试图提交玩家资产、线上数值或战斗结算写操作时，调用被 L0 边界拒绝并留下审计记录。 | FR-AGS-002/003、NFR-AGS-001 |
| **AC-AGS-003** | 仿真或模型服务不可用时，实时游戏循环和账本路径继续按确定性逻辑运行，受影响 Agent 明确降级。 | FR-AGS-001～004、NFR-AGS-003 |
