## 4. 架构设计方针（ARC-054）

### 4.1 ARC-054：智能体平台统一运行时与多 Agent 协同架构（重要决定）

Agent Platform 统一承载编排、工具注册、记忆、成本与审计能力，但不拥有业务状态的直接写权限。平台必须保持 L0〜L4 的单向权限边界：非确定性层只能形成受签名、时效、nonce 与证据链约束的 `ActionIntent`，实际写入仍由下游 L0 确定性闸门裁决。该约束由 ADR-0054 记录，并继承 ADR-0029 与 ADR-0053 的默认拒绝原则。

任一平台故障、分区、密钥异常或审计证据缺失时，运行时必须 fail-closed：停止受控动作提交、保留可重放审计记录，并把人工处置作为唯一升级路径。
