## 4. 已知缺口 (per 缺标比错标安全)

### 4.1 GAP-V03-1: card / leaderboard 域无 k8s deployment
- **现状**: rgs-flash-mock 7 域 client pool 已就绪, 但 card-service + leaderboard-service 域尚未部署到 k3s
- **原因**: card + leaderboard 域在 `feat/auto-20260910-e02e3cef` worktree 不在 main, k8s manifests 也没在 main
- **影响**: /card/collection + /rank/leaderboard (v0.3) 在 k3s 内 mTLS 业务级 ST 走 fallback 模式 (success=false 但 endpoint 实施 OK)
- **缓解**: 主会话后续负责 k3s 部署 card + leaderboard 域; 部署完成后, 上述 endpoint 自动 success
- **非 rgs-flash-mock 责任**: 卡牌域 / 排行榜域 deployment 跟 mock 项目解耦

### 4.2 GAP-V03-2: leaderboard helper 全部 4 RPC (GetRanked + GetCasual + GetCollection + GetPlayerRank) 暂只实装 GetRanked
- **现状**: v0.3 仅实装 GetRankedLeaderboard (RPC 1001 用), 4 类榜单其它 3 个未在 handler 接入
- **影响**: /rank/leaderboard endpoint 走 GetRanked (天梯榜 weekly period)
- **后续**: v0.4+ 扩 3 榜单类型 + 4 RPC 全实装 (per 9 月底 ST 计划)

### 4.3 GAP-V03-3: card 业务级 RPC 仅 2/9 实装
- **现状**: v0.3 仅实装 HealthCheck + GetPlayerCollection (RPC 1201)
- **未实装**: GetCard / ListCards / GetCardSeries / ListCardSeries / AddCardToCollection / RemoveCardFromCollection / OpenPack (7 RPC)
- **影响**: 8 类别 80 RPC (估算) 1/9 sampled (per gap_matrix Card 类别)
- **后续**: v0.4+ 扩 card RPC 全实装 (catalog / series / pack opening)

### 4.4 GAP-V03-4: 7 域 binary 仍走 fallback 模式 (无真实 gRPC backend)
- **现状**: 本地端口 8791 启动 OK, 7 域 gRPC pool 初始化 OK, 但无任何 k3s 5 域 + card + leaderboard binary 在跑
- **影响**: 所有 endpoint 返回 pass-fallback (实施 OK 但无真实业务数据)
- **非 rgs-flash-mock 责任**: 5 域 + card + leaderboard binary 部署在主会话跟 SRE 后续
- **rgs-flash-mock 责任**: client pool 实施 OK, 实施 7 域 mTLS 调用框架

### 4.5 GAP-V03-5: DLQ-retry 不在 rgs-flash-mock 责任范围
- **现状**: per 9/1 14:58 JST 守门 #3 — 5 域 binary saga 内 NATS DLQ, 不是 rgs-flash-mock 责任
