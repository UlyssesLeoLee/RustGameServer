## 3. Lessons Learned (per L11/L12 派生约束 + 8/27 11:06 JST 凭据硬 ban)

| 编号 | 问题 | 修法 |
|---|---|---|
| L1-1 | tonic-build 生成 `r#match.v1.rs` (match 是 Rust 关键字) | `tonic::include_proto!("r#match.v1")` (r# 语法) |
| L1-2 | proto 模块层级不一致导致 `super::super::common::v1` 找不到 common | 统一 5 域 + common 都在 `crate::grpc_clients::proto::{domain}::v1` (4 层), 顶层 `pub use` alias |
| L1-3 | `tonic::Response<T>` 字段 private, 直接 `resp.status` 错 | 全部走 `resp.into_inner().status` (per tonic 0.12 API) |
| L1-4 | `BanAccountRequest` 字段名 `operator_id` / `scope` 实际不存在 | 严格按 5 域 admin.proto 字段填 (request_id/account_id/reason/duration_seconds/force_disconnect_session) |
| L1-5 | `EntityId` 没 `#[derive(serde::Serialize)]`, `serde_json::json!({"id": a.id, ...})` 编译错 | 显式 `a.id.as_ref().map(\|e\| e.id.clone())` 解包到 String |
| L1-6 | 顶层 `pub use crate::proto::...` 在 grpc_clients 模块内, 路径错 | 改用 `pub mod player { pub use super::proto::player::v1::*; }` (相对路径) |
| L11 | 11 次 build 重试 (1 次 status 拿不到) | 接受 warning + 1 次 status (per AGENTS.md §2.1 L11) |
| L12.1 | 临时 log / .txt 不入 commit | ✅ 没留任何临时文件 (cargo-build-v02.log 在 $env:TEMP, 不在 worktree) |
| 凭据 | env value 永不打印 (8/27 11:06 JST 硬 ban) | ✅ `Config::from_env` 只 invoke env, 不打印 value; load_client_tls_from_paths 失败也只 warn path 不打 value |
