## 1. 总体架构

### 1.1 架构选型

采用 **零依赖纯静态前端** + **本地 JSON 数据** 方案：

```
┌────────────────────────────────────────────────────────────────┐
│                         浏览器 (Chrome/Edge/FF)                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ index.html                                              │  │
│  │   ├─ <link> styles.css                                   │  │
│  │   └─ <script type="module"> main.js                      │  │
│  │                                                          │  │
│  │ main.js (ES Module)                                      │  │
│  │   ├─ state.js        ── 全局状态 (activeTab, search…)    │  │
│  │   ├─ data-loader.js  ── fetch('data/api.json')           │  │
│  │   ├─ tabs.js         ── 一级/二级选项卡渲染              │  │
│  │   ├─ list.js         ── 列表渲染 + 搜索过滤              │  │
│  │   ├─ modal.js        ── 详情弹窗 + 焦点陷阱              │  │
│  │   └─ codeblock.js    ── 代码块轻量语法高亮                │  │
│  └──────────────────────────────────────────────────────────┘  │
│  ▲                                                             │
│  │ fetch() / static file                                       │
│  ▼                                                             │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ data/                                                    │  │
│  │   ├─ api.json          ── API 主数据                      │  │
│  │   ├─ categories.json   ── 引擎 → 类别映射                │  │
│  │   └─ i18n.json         ── UI 文案（v0.1 仅 zh-CN）         │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────┘
              ▲
              │ HTTP (GET /index.html, /data/*.json)
              │
┌────────────────────────────────────────────────────────────────┐
│  本地 HTTP 服务（任选其一）                                    │
│    • python -m http.server 8000                                │
│    • npx http-server -p 8000                                   │
│    • tools/rgs-web/server.js （复用现有 dev server）           │
└────────────────────────────────────────────────────────────────┘
```

**关键决策**：

- **ES Module** 而非打包工具：无需 webpack/vite，浏览器原生支持，降低维护成本
- **零运行时依赖**：不引入任何 npm 包（包括 highlight.js / prism），代码高亮用 50 行的轻量正则实现
- **数据驱动**：UI 完全由 `api.json` 决定，新增 API 零代码改动

### 1.2 与 RGS 现有架构的关系

- **不进入** RGS 5 域限界上下文（player / economy / match / social / admin）
- **不进入** RGS 三层文档治理体系（REQ / BAS / DTL）
- 属于 **开发者工具 / DX 工具**，与 `tools/db-seed`、`tools/rgs-web` 平级
- 与 Physis 物理引擎的 C ABI 通过 `data/api.json` 中的 `physis` 示例字段关联（只读引用，不调用）

### 2.2 选项卡状态机

```
[Engine: All] ──┐
[Engine: Unity]─┤
[Engine: UE]   ─┼─→ [Category: All] ──→ list = api.filter(...)
[Engine: Godot]┤    [Category: 发射]  ──→ list = api.filter(engine ∩ category)
[Engine: Physis]┘    [Category: 生命周期]
                     ...
```

**状态定义**（`state.js`）：
```js
const state = {
  engine: 'all',      // 'all' | 'unity' | 'unreal' | 'godot' | 'physis'
  category: 'all',    // 'all' | <engine-specific category id>
  search: '',         // user input string
  selectedApiId: null // current modal target; null = closed
};
```

**状态变化触发**：
- 切换 engine → 重置 category 为 'all'（因为类别是 engine 维度的子集）
- 切换 category → 过滤 list，不重置 search
- 修改 search → 实时过滤 list
- 点击 API → 设置 selectedApiId → 打开 modal

### 2.3 详情弹窗结构

```
┌────────────────────────────────────────────────────────────┐
│ [×]                                                  ESC 关闭│
│                                                            │
│ API 标题: ParticleSystem.Emit                              │
│ 引擎徽标: [Unity]   类别: 发射    标签: [Emit] [Burst]    │
│ ─────────────────────────────────────────────────────────  │
│                                                            │
│ ┌─ 弹窗内一级 tab ─────────────────────────────────────┐   │
│ │ [概述] [参数] [示例] [注意事项] [引擎差异]            │   │
│ └──────────────────────────────────────────────────────┘   │
│                                                            │
│ 当前 tab: 示例                                             │
│ ┌─ 弹窗内二级 tab（仅"示例"tab 显示） ─────────────┐       │
│ │ [Unity] [Unreal] [Godot] [Physis]                │       │
│ └──────────────────────────────────────────────────┘       │
│                                                            │
│ 当前二级 tab: Unity                                        │
│ ┌────────────────────────────────────────────────────┐     │
│ │ // Unity C#                                       │     │
│ │ var ps = GetComponent<ParticleSystem>();           │     │
│ │ ps.Emit(50);  // 立即发射 50 个粒子                 │     │
│ │                                                    │     │
│ │ // 适用：命中特效、爆炸、伤害飘字等瞬时场景        │     │
│ └────────────────────────────────────────────────────┘     │
│                                                            │
│ [关闭]                                                     │
└────────────────────────────────────────────────────────────┘
```

**弹窗内一级 tab 与二级 tab 的关系**：
- "概述" / "参数" / "注意事项" / "引擎差异"：这 4 个 tab **不显示**二级引擎 tab
- 仅 "示例" tab 显示二级 tab（Unity / Unreal / Godot / Physis）

**引擎差异 tab 内容**：以表格形式横向对比同一概念在各引擎下的语义。

## 3. 交互流程

### 3.1 主路径：浏览 → 查看详情

```
User                UI                    State                Data
 │                   │                      │                     │
 │ 打开页面          │                      │                     │
 ├──────────────────→│ 初始化                │                     │
 │                   ├─ load api.json ──────┼────────────────────→│
 │                   │                      │ ←── api.json ───────┤
 │                   ├─ render tabs         │                     │
 │                   ├─ render list         │                     │
 │                   │                      │                     │
 │ 点击 "Unity" tab  │                      │                     │
 ├──────────────────→│ state.engine=unity   │                     │
 │                   ├─ filter list         │                     │
 │                   ├─ render sub-tabs     │                     │
 │                   │                      │                     │
 │ 点击 "发射" 子tab │                      │                     │
 ├──────────────────→│ state.category=发射  │                     │
 │                   ├─ filter list         │                     │
 │                   │                      │                     │
 │ 点击列表项        │                      │                     │
 ├──────────────────→│ state.selectedId=X   │                     │
 │                   ├─ open modal          │                     │
 │                   ├─ show 概述 tab       │                     │
 │                   │                      │                     │
 │ 点击 "示例" tab   │                      │                     │
 ├──────────────────→│ show 示例 tab        │                     │
 │                   │   + 二级引擎 tab     │                     │
 │                   │                      │                     │
 │ 点击 "Godot" 子tab│                      │                     │
 ├──────────────────→│ show godot 代码块    │                     │
 │                   │                      │                     │
 │ 按 ESC            │                      │                     │
 ├──────────────────→│ close modal          │                     │
 │                   ├─ state.selected=null │                     │
 │                   │                      │                     │
```

### 3.2 搜索流程

```
User                UI                    State
 │                   │                      │
 │ 按 "/" 键         │                      │
 ├──────────────────→│ focus search input   │
 │                   │                      │
 │ 输入 "emit"       │                      │
 ├──────────────────→│ onInput              │
 │                   ├─ state.search='emit' │
 │                   ├─ filter list         │
 │                   ├─ re-render list      │
 │                   │                      │
 │ 按 ESC            │                      │
 ├──────────────────→│ blur + clear         │
 │                   │  (可配置:保留搜索词)  │
```

### 3.3 键盘导航

| 键 | 行为 |
|----|------|
| `/` | 聚焦搜索框 |
| `↑` / `↓` | 列表项上下移动 |
| `Enter` | 打开选中项详情 |
| `Esc` | 关闭弹窗 / 退出搜索 |
| `Tab` (在弹窗内) | 在 tab / 按钮 / 代码块间循环，焦点不外溢 |
| `1`-`5` (在弹窗内) | 切换弹窗内一级 tab（概述/参数/示例/注意事项/引擎差异） |

### 4.2 启动方式

**方式 1：复用现有 rgs-web dev server（推荐）**
```bash
cd D:/RustGameServer/tools/rgs-web
node server.js
# 浏览器打开 http://localhost:<port>/particle-api-browser/
```

**方式 2：Python 内置服务**
```bash
cd D:/RustGameServer/tools/rgs-web/particle-api-browser
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

**方式 3：npx http-server**
```bash
cd D:/RustGameServer/tools/rgs-web/particle-api-browser
npx http-server -p 8080 -c-1
```

### 4.3 file:// 协议的取舍

`fetch('data/api.json')` 在 `file://` 协议下大多数浏览器会因 CORS 拒绝。

**决策**：
- **主推 HTTP 方式**（方式 1-3）
- 兜底：在 `index.html` 头部内联一份"默认数据"——若 fetch 失败则使用内联数据降级（v0.1 不实现，留作 v0.2 任务）

### 4.4 与 rgs-web 现有 server.js 的集成

- 不修改 `tools/rgs-web/server.js` 主代码
- 仅在 README 注明"将 particle-api-browser 目录视为静态资源即可"
- 若现有 server.js 有路由白名单，按需追加

## 5. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| `api.json` 维护成本高 | 数据陈旧 → 工具价值衰减 | v0.1 仅录入 8-12 条；按"高频使用"优先 |
| 各引擎 API 版本差异 | 文档可能误导 | 顶部固定显示"基线版本"（如"Unity 2022.3+ / UE 5.3+ / Godot 4.2+ / Physis 0.4+"） |
| 用户在弹窗内被焦点陷阱卡住 | A11y 差 | 提供清晰的 ESC 提示 + 焦点循环 |
| `file://` 协议下数据加载失败 | 双击 HTML 失效 | README 显式说明必须用 HTTP 方式 |
| 多浏览器兼容性 | Chrome 之外可能样式异常 | v0.1 仅承诺 Chrome / Edge 主验，其他浏览器 v0.2 覆盖 |
